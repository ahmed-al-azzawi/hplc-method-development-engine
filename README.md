# HPLC Method Development Engine
The application serves to automate isocratic method development according to the user specification. It is intended to have a friendly user interface and be compatible with Shimadzu LabSolutions CSV files.

Access online at https://ahmed-hplc.streamlit.app or preferably use the HTML file. The HTML file is faster, so it is preferable.
